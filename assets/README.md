## Activity images

The activity and language images use the public [GitHub Stats Extended](https://github.com/stats-organization/github-stats-extended) endpoint. Requests send only the public GitHub username and visual options; no token is configured. The stats card explicitly sets `count_private=false`, hides ranking, and excludes the all-years commit option.

These images depend on the third-party service and GitHub's image cache. Public repository links and alt text remain available if they fail. Language percentages represent public code volume, not proficiency. Do not replace them with made-up numbers, private repository data, or private credentials.
